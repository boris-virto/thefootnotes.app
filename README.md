# thefootnotes

Телеграм-бот, который помогает не забывать всякие штуки. Кидаешь ему текст, голосовое,
скриншот билета или PDF — он разбирает смысл через Claude, сохраняет структурированное
напоминание и показывает всё на веб-дашборде.

## Что внутри

- **Бот** — python-telegram-bot (текст / войс / фото / PDF)
- **Транскрипция войсов** — OpenAI Whisper
- **Разбор смысла и чтение билетов** — Claude (Anthropic), с поддержкой vision и PDF
- **Хранилище** — SQLite (файл `data/thefootnotes.db`)
- **Напоминания** — регулярные пинги, пинг «за день до события» и утренний дайджест списком в 9:00 (`/digest` — вызвать вручную)
- **Дашборд** — FastAPI + одна HTML-страница, вход по Telegram (Login Widget), доступ только для `ALLOWED_USER_IDS`
- **JSON API** — `/api/v1` для мобильных клиентов, авторизация по токену устройства (см. [«На iPhone»](#на-iphone))
- Бот и веб работают **в одном процессе** (бот в режиме polling запускается вместе с сервером)

## Что нужно достать перед стартом

1. **Токен бота** — напиши [@BotFather](https://t.me/BotFather), `/newbot`, скопируй токен.
2. **Ключ Anthropic** — https://console.anthropic.com/ → API Keys.
3. **Ключ OpenAI** — https://platform.openai.com/ → API keys (нужен для войсов).
4. **Свой telegram user id** — напиши [@userinfobot](https://t.me/userinfobot), чтобы закрыть бота только для себя.

## Локальный запуск

```bash
cd thefootnotes
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env      # затем впиши ключи в .env

uvicorn app.main:app --reload --port 8000
```

- Дашборд: http://localhost:8000
- Бот заработает сразу после старта — напиши ему в Telegram.

## Деплой на VPS (Debian) + GitHub Actions

Полный пошаговый runbook — в [`deploy/DEPLOY.md`](deploy/DEPLOY.md). Кратко:

- бот и дашборд крутятся как systemd-сервис под непривилегированным пользователем;
- nginx отдаёт дашборд по HTTPS с паролем на домене `thefootnotes.app`;
- данные (SQLite + файлы) лежат на реальном диске и не теряются;
- каждый `git push` в `main` автоматически выкатывается на сервер (`.github/workflows/deploy.yml`);
- адрес базы вынесен в `DATABASE_URL` — переезд на PostgreSQL не требует правок кода.

## Структура

```
app/
  config.py      настройки из окружения
  db.py          модель Reminder + SQLite
  llm.py         разбор текста/картинок/PDF через Claude
  transcribe.py  войсы -> текст (Whisper)
  ingest.py      захват: вход -> разбор -> карточка (общий для бота и API)
  bot.py         хендлеры телеграм-бота
  api.py         JSON API /api/v1 для телефона
  tokens.py      коды спаривания и токены устройств
  main.py        FastAPI-дашборд + запуск бота
  templates/     HTML дашборда
```

Захват намеренно вынесен в `ingest.py` и ничего не знает про Telegram: карточка,
присланная в чат, и карточка из мобильного клиента проходят один и тот же путь.

## На iPhone

Нативное приложение — следующий шаг (нужен Xcode и аккаунт разработчика). Серверная
часть под него уже готова: `/api/v1` отдаёт доску, принимает захват и умеет
синхронизацию по изменениям. До появления приложения тем же API пользуется шорткат iOS.

### Токен устройства

Любой клиент авторизуется одинаково: код из бота меняется на долгий токен.

1. В боте: `/pair` — он выдаст код вида `ABCD-EFGH` (живёт 10 минут, работает один раз).
2. Обменяй код на токен:

```bash
curl -s -X POST https://thefootnotes.app/api/v1/pair \
  -H 'Content-Type: application/json' \
  -d '{"code":"ABCD-EFGH","device_name":"Шорткат"}'
# -> {"token":"...","user_id":...}
```

Токен долгий и не истекает — отозвать можно через `DELETE /api/v1/devices/{id}`.
Приложение будет спрашивать код при первом запуске и обменивать его само.

### Шорткат: кинуть что угодно в сноски из любого приложения

Пока нет приложения с Share Extension, меню «Поделиться» закрывает шорткат
(Приложение «Быстрые команды» → новая команда):

1. В настройках команды включи **«Показывать в меню «Поделиться»»**, а в типах входа
   оставь «Текст», «URL-адреса», «Изображения», «Файлы».
2. Действие **«Получить содержимое URL-адреса»**:
   - URL: `https://thefootnotes.app/api/v1/capture`
   - Способ: `POST`
   - Заголовок: `Authorization` = `Bearer <твой токен>`
   - Тело запроса: **Форма**
     - для текста и ссылок — поле `text`, значение «Вход команды»;
     - для картинок и PDF — поле `files` типа «Файл», значение «Вход команды».
   - Если хочешь один шорткат на всё, поставь перед этим «Если» по типу входа и сделай
     две ветки с разными полями формы.
3. Действие **«Получить значение из словаря»**: ключ `card.title` — и «Показать
   уведомление», чтобы видеть, что именно сохранилось.

Скажи Siri название команды — и она попросит надиктовать заметку: голос распознает
сам iOS, серверу уедет готовый текст.

### Что понадобится приложению

Новых эндпоинтов не нужно: `GET /api/v1/board` даёт доску целиком, а
`GET /api/v1/cards?since=<server_time из прошлого ответа>` — только изменения, чего
хватает и виджету, и офлайн-кешу. Остаётся клиентская часть: Xcode, аккаунт
разработчика ($99/год), Share Extension вместо шортката и APNs, если однажды
захочется пуши не через Telegram.

## JSON API

Авторизация: `Authorization: Bearer <токен>` (или сессионная кука дашборда).
Всё, кроме `/pair`, без токена отвечает `401` в JSON — без редиректов на HTML.

| Эндпоинт | Что делает |
|---|---|
| `POST /api/v1/pair` | код из `/pair` → токен устройства |
| `GET /api/v1/me` | проверить токен |
| `GET /api/v1/board` | доска: три колонки + `server_time` (курсор для `since`) |
| `GET /api/v1/cards?since=&status=` | список; `since` отдаёт только изменённое, включая архив |
| `GET /api/v1/cards/{id}` | одна карточка |
| `GET /api/v1/cards/{id}/files/{n}` | скачать n-е вложение |
| `PATCH /api/v1/cards/{id}` | `status` / `importance` / `remind_active` |
| `POST /api/v1/capture` | multipart: `text` и/или `files` (фото, PDF, голосовое) |
| `GET`/`DELETE /api/v1/devices` | привязанные устройства и отзыв доступа |

Время везде в UTC с `Z`. Курсор для синхронизации бери из `server_time` ответа, а не
с часов телефона. Живая схема — на `/docs`.

Карточка из API получает `chat_id` владельца, поэтому напоминания за день до события
приходят в Telegram так же, как у карточек из чата.
